Tessera Expansion Workshop

Extract the ZIP and open Tessera-Expansion-Workshop.html in Chrome, Edge or
Firefox. In the full authoring kit, the file is called expansion-editor.html.
The editor works offline on Windows and Linux.

1. Name your set and choose a set ID.
2. Choose a group. Drop artwork onto Add card in the tier you want.
3. Edit the card's name, values, rarity, group and affinity. Choose how players
   can get it, then adjust the artwork crop.
4. Save project keeps an editable backup with your artwork.
5. Export expansion creates a ZIP to install as a separate MO2 or Vortex mod.
   Fully restart Skyrim to load it.

The browser also saves your draft. Keep project backups before moving the
editor, changing browsers or clearing browser data. Keep original art separately.

Open a project, expansion ZIP or mod folder to continue editing. If you open
only a JSON file, supply its matching images too. You can add as few cards as
you want; there is no need to fill every tier.

Tessera tier rules checks the usual card strengths. Choose Custom values if you
want different strengths. Once you publish a set, keep its set ID and card IDs
unchanged. Names, values and artwork can be updated.

Exports contain the JSON and artwork in these folders:
  SKSE/Plugins/Tessera/Expansions/<set-id>.json
  TesseraUI/art/expansions/<set-id>/faces/<card-id>.webp
  TesseraUI/art/expansions/<set-id>/thumbs/<card-id>.webp

The editor adds no text or numbers to the pictures; Tessera draws them in game.

The source includes example card definitions and guides for card settings,
tournament prizes, NPC collections and quest rewards. Supply your artwork
at the paths declared in each example.
