# Expansion authoring

Open [Expansion Workshop](expansion-editor.html) in your browser. It works offline.

[Creating a card expansion](card-expansions.md) covers the editor, card settings and ways to earn cards. [Opponent integrations](opponent-integrations.md) covers NPC collections, dialogue and quests.

The source includes example card definitions under `examples/`. Supply your own images at their declared paths, or start a set in the editor and import your artwork.

Save a project to keep an editable copy. Export an expansion ZIP to install or distribute your set. Choose stable set and card IDs before publishing.
