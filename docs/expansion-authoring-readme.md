# Tessera Expansion Authoring

Extract this ZIP and open `expansion-editor.html` in your browser. The editor works offline.

Start with [Creating a card expansion](card-expansions.md). It covers the editor, card settings, artwork and ways to earn cards in game.

The `example` folder contains **My Cool Cards**, a complete three-card expansion. You can open that folder in the editor or zip its `SKSE` and `TesseraUI` folders together to install it as a separate mod. It requires Tessera 0.30.0 or later and the Card Art download.

For NPC collections and custom opponents, see [Adding Tessera opponents](opponent-integrations.md). The optional `opponent-example` gives Hulda cards from My Cool Cards. `opponent-templates` and `Scripts/Source` are for authors adding their own NPCs or quest rewards.

The full authoring kit is for editing. Distribute the expansion ZIP you export from the editor. Choose your own set ID and card IDs before publishing.

Artwork paths are described in [Replacing card art](card-art-replacers.md).
